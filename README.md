# ☕ Shaina Cafe

A modern and responsive café website built with **React.js** and **Tailwind CSS**.
The website is designed to provide a smooth and engaging experience for customers to explore the café, browse its offerings, check the location, and make a table reservation.

## 🌐 Preview

A modern cafe interface with a soft pastel color palette, responsive layouts, smooth scrolling, animations, and an easy-to-use reservation system.


![HomePage](./public/images/Demo%20img%201.png)

![Moments](./public/images/Demo%20img%202.png)

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Sanjugupta65/Shaina-Cafe.git
```

### 2. Navigate to the project

```bash
cd shaina-cafe
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. View in Browser

Once the project starts running, open your browser and navigate to:
```
 http://localhost:5173
```

The application will be available at the local development URL shown in your terminal.

## 🎨 Design

The website uses a soft café-inspired visual style with:

* Pastel pink
* Lavender
* Light blue
* Dark purple backgrounds
* Rounded cards
* Smooth transitions
* Responsive layouts

The design focuses on creating a warm, modern, and comfortable café atmosphere.

## 📱 Responsive Design

The website is designed to work across:

* 💻 Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile

Tailwind CSS responsive utilities are used to adapt the layout to different screen sizes.

## 📅 Reservation System

Customers can open the reservation modal and provide:

* Name
* Phone number
* Date
* Time
* Number of guests
* Special requests

The reservation interface also supports a cart summary and confirmation state.

> Note: The current reservation system is a frontend implementation. A backend or database can be connected later for storing real reservations.
